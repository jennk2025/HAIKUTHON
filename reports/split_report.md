## 확인 범위

- 확정 중복: 파일 바이트, 디코딩 픽셀, 정규화 텍스트가 완전히 같은 경우
- 유사 데이터: 지각 해시(pHash)와 단어 Jaccard로 찾을 수 있는 범위만 확인했다.
- 임베딩 기반 의미 유사도(같은 장면을 다르게 그린 이미지 등)는 확인하지 않았다.

## 사용 규칙

- 검증 ID는 학습에 쓰지 않는다.
- 검증 ID로 증강 데이터를 만들지 않는다.
- 검증 ID를 hard negative 채굴 대상으로 쓰지 않는다.

from haiku.data import load_rows, load_split
